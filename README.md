# SmarThink: E-learning Platform Frontend

Frontend for **SmarThink**, a gamified e-learning platform with courses, modules, progress maps, quizzes, rankings and chat. Built as a 6-person team for the **Interaction Design** course at Universidad Austral (2024).

The goal was to turn Figma wireframes and a design system into a library of reusable, documented components.

## Highlights
- **50+ reusable components** documented in Storybook: course and module cards, carousels, progress bars, a course progress map, quiz Q&A, podium and ranking tables, chat bubbles, calendar, time picker, week selector, nav bar, modals and more.
- **Pages:** Home and Course Map.
- **Design-system fidelity:** colors, typography and states follow the team's design system and wireframes.

## My contributions
The calendar, time picker, chat bar and message bubbles; the progress map page; and design-system alignment across components (search bar, subject tags, Storybook parameters).

## Run it
```bash
npm install
npm run storybook   # browse the component library at http://localhost:6006
npm start           # run the app at http://localhost:3000
```

**Stack:** React · TypeScript · Tailwind CSS · Material UI · Storybook
